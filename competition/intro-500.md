# 作品简介（500 字以内）

> GOAI 初赛·材料一｜赛道 1 新智基座 Agent Infra

**项目名称：折返治理 Switchback —— 多 Agent 协同的人机监理治理框架**

**问题与场景**：多 Agent 系统从 Demo 走向生产，最难的不是跑通，而是结果不可信、过程不可停、出事不可回、账目不可审。在京张 AI 创新带开源征集（open-city-ai/haidian）16 轮真实迭代中，亲历数值对不齐、CRLF 哈希错位、标记漂移 42 处等全部治理事故，最终拿到 84/100 最高纪录。

**核心解决方案**：以京张铁路青龙桥"人字形折返"为制度原型，构建"到站必停、三方复核、不设自动恢复"的治理协议：①折返点：到点必停，任何一方否决即强制折返；②坡度分级准入：缓/中/陡三级，越陡复核越严；③K 标版本：内容寻址哈希链，永久留痕；④道岔三态：正线/侧线折返/入段检修，不设自动恢复。以 AgentTeams 为设计基点编排 6 个 Agent、闭环 8 步、六大可复用 Skill、OTel 可观测与 MCP 集成契约。

**创新点与差异化**：不堆叠工具，把"人机监理"制度化为可复算、可审计、可接手的协议；旗舰案例是真实竞赛 84 分闭环，非对话 Demo。

**开放/复用价值**：零依赖 Python 实现全量开源（Apache-2.0）；Skill 与协议解耦，可沉淀进 AgentTeams 生态；协议可复制到运维/客服/研发/金融风控四方向。

**当前进展**：核心协议 + 43 项测试 + 双案例可复现重放已开源。
