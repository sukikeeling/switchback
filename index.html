折返治理 · Switchback

Switchback Governance — the Human-in-the-Loop Governance Layer for Multi-Agent Teams
让每一次 Agent 决策，都沿轨道可查、可停、可回头。
这是什么？ 一层多 Agent 协同的人机监理治理协议。以京张铁路青龙桥"人字形折返"为制度原型——列车遇陡坡必停、换向、以退为进；任何 Agent 决策同样必须"到站必停、三方复核、不设自动恢复"。

旗舰证据：京张 AI 创新带开源征集 84/100 最高纪录（open-city-ai/haidian），真实竞赛闭环，非对话 Demo。

⑤ 四大机制

① 折返点 Switchback Node — 任务到点必停，任何一方否决即强制折返，不自动续行
② 坡度分级 Grade-based Access — 缓/中/陡三级，越陡复核越严（陡坡需三方）
③ K标版本 K-marker — 内容寻址哈希链，永久留痕，篡改即断链
④ 道岔三态 Switch States — 正线/侧线折返/入段检修，不设自动恢复

⑥ 六大可执行 Skill

Skill功能
grade-access坡度分级准入
evidence-verify证据核验（数值三处对齐 + 引用双向 + 内容哈希）
kmarker-ledgerK标账本（不可变哈希链）
risk-ledger风险台账（score≥4 强制人工复核）
switch-decision折返裁决（三方复核，任何否决即折返）
lessons-learned经验沉淀（复盘写回 Agent 记忆）
